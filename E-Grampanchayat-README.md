# E-Grampanchayat System

E-Grampanchayat is a web-based village administration platform developed to simplify the management of citizen registrations, service requests, and grievance redressal.

## Features

- Citizen registration
- Citizen management
- Service request management
- Grievance registration
- Grievance redressal
- Village administration dashboard
- Centralized record management
- Simple and user-friendly interface

## Tech Stack

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Project Overview

The E-Grampanchayat system provides a digital platform for managing common village administration activities.

Instead of handling different records and requests manually, the system brings citizen information, service requests, and grievances into one web-based application.

## Main Modules

### Citizen Management

Allows administrators to manage citizen information and registrations.

### Service Requests

Provides a way to manage requests submitted by citizens for different village services.

### Grievance Redressal

Allows citizens to submit grievances and provides administrators with a system to manage and resolve them.

### Administration

Provides an administrative interface for managing records and monitoring requests.
